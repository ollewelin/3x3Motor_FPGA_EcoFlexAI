# TI60F225_ECO_FLEX_AI_1

Minimal example repository for 1 Gbit UDP TX on Ti60 FPGA (personal project).

- This repo contains the user's Verilog and C examples for bringing up a 1Gbit
  UDP transmitter and related drivers.
- Efinix-generated SoC / BSP files are excluded from the public view and are
  not tracked here (they were removed from the index and are ignored).

Files to note:

- `embedded_sw/SoC_mini_A/software/standalone/lite_soc_a/makefile`
- `embedded_sw/SoC_mini_A/software/standalone/lite_soc_a/src/lite_soc_a.c`
- `embedded_sw/SoC_mini_A/software/standalone/driver/mdio_driver.h`
- `embedded_sw/SoC_mini_A/software/standalone/driver/mdio_driver_Ti60.h`
