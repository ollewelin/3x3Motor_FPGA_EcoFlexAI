Restore known-good OpenOCD configs
---------------------------------
If the BSP or SoC files are regenerated and overwrite the openocd configs, restore these known-good files by running from the repo root:

  bash debugger_settings/RISC_mini_debugg_config/restore_openocd_cfgs.sh

This script backs up existing files in the BSP openocd directory and copies in the local copies from this folder.
